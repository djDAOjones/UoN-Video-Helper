# VH-53 — Repository review remediation

> **Status:** Band 1, in progress on `codex/repository-review-implementation`.

## Intent and boundary

Implement the highest-severity verified, non-protected review findings with
deterministic and real-browser evidence. Work is isolated in `/private/tmp`
because the reference checkout is OneDrive-synced; project memory remains on
the branch. Protected specifications, meter code and the EBU harness remain
unchanged unless a coupled change is separately approved.

## Implemented on this branch

- Immutable selection and result authorities reject stale readiness, overlap,
  implicit replacement and false download completion. The safe save route uses
  a selected directory, app-owned numbered names and source identity checks;
  the truncating single-file save picker is never invoked.
- Cancellation reaches both media lanes and finished-output verification, with
  retryable cleanup. Save cancellation retains the result; wake/unload
  protection spans processing, saving and retained output. A watchdog interlock
  keeps Start closed until a silent worker answers terminally.
- Inspection, probe and encode share Mediabunny's primary tracks and one source
  clock. Delays and gaps use bounded zero-fill. Complete-chain gain solving and
  decoded-output classification enforce both loudness and true-peak limits.
- OPFS directories are claimed before creation and deleted only while the same
  origin-wide lock is held. A project-owned bridge lets Mediabunny retain its
  writer without hiding the raw fallback stream from cancellation cleanup.
- Acceptance and cross-engine checks distinguish pass, fail, partial and manual
  evidence. A protocol watcher observes main/worker requests and WebSockets
  without retaining raw bodies, paths, headers or frames; eleven nonce-bound
  controls prevent a missing observer from passing silently.

## Evidence recorded

Chromium acceptance had no automated failure. The normal app measured private
source `AMCS3059` at **−16.46 LUFS / −2.06 dBTP**; independent FFmpeg reported
**−16.50 LUFS / −2.06 dBTP**. Its H.264/AAC output is 852×480 at 30 fps, 48 kHz
stereo and 134.4 s. `CULT2011` passed pre-flight but remains an AAC compatibility
case. The 23 samples cover VH-50, not mobile/HDR risk.

Fresh-origin OPFS rehearsals passed in Chrome 151, Firefox 154 and Safari
26.5.2. All three exercised main-thread fallback commit, the real worker sync
writer, cross-worker exclusion and exact-directory recovery after forced worker
termination: **3 completed, 0 skipped, 0 failed**.

Chrome's protocol egress run completed a silent production-worker job plus
acknowledged discard and the full AAC acceptance run, passing **all 11
controls**. Its clean-record count varies with Vite reloads and is diagnostic,
not a benchmark. Firefox completed the supported silent job with **90 clean
records and all 10 observable request-lifecycle controls**, but correctly fails
the full proof because WebDriver BiDi exposes no outgoing WebSocket-frame event.
Safari is unsupported because safaridriver/WebDriver Classic exposes no usable
request-event stream.

## Still open before VH-53 can close

- **Protected:** a first-class detector-tail API, LRA tail semantics and a
  bounded derived-curve design require explicit approval and the unchanged EBU
  Tech 3341 harness.
- **Human/browser:** rehearse OneDrive directory selection, collisions,
  cancellation and permission changes; large fallback, private/multi-tab,
  sleep/reload, keyboard/assistive technology and device storage pressure. The
  directory API has no exclusive-create primitive; its final external race
  remains explicit. Retained fallback results stay until known safe.
- **Protocol:** find a trustworthy Firefox/Safari WebSocket-frame observation
  route, or retain the explicit partial/unsupported result.
- **Media:** verify first-picture/AAC sync in independent players, 4K60 on real
  encoders, additional-track selection, genuine offset/gapped media and
  metadata round-trip.
- **Governance:** branding/legal provenance remains a maintainer decision;
  hashes prove identity, not permission to publish.

No pilot blocker closes from unit tests alone. No runtime dependency,
whole-file processing buffer, protected meter change or EBU tolerance change
was introduced.
