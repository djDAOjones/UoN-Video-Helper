# VH-165 — Two CSS repairs: long words wrap inside their column, and the trim handles' forced-colour ring takes its system colour

## Intent

The design pass of 22 October measured a finished result at 320 px whose file name ran 1,105 px past the window, and a student ID's error that ran 721 px past its column; both made the page scroll sideways, a WCAG 1.4.10 failure, and text spacing made them worse (V-34). An ordinary name does the same, because underscores are not break points. This item lets a word longer than its line break where it must, in our own CSS, so every character of the user's own file name and ID stays readable on a phone. It also splits one forced-colours rule Chrome drops whole, because it names a Firefox pseudo-element beside Chrome's, so the trim handles' focus ring takes `CanvasText` as UI-STANDARDS asks (V-38).

## Acceptance criteria

- V-34: `overflow-wrap: anywhere` on the shared running-text rule (`app.css:36`) and the prose spans it misses, so the notification body, status lines and field errors break a word only when it is longer than its line; not on controls; no clipping, ellipsis or `word-break: break-all`.
- V-38: the forced-colours rule at `app.css:1653` split into one rule per engine, as `:1414` and `:1419` are; the focused thumb's ring checked in a light and a dark forced palette.
- The finished result, the previous result and the discard question with a file named 100 `W`s and `.mp4`, and with `Lecture_Week_3_Introduction_to_Biochemistry_v2.mp4`, and a 100-character student ID's error: no sideways scroll at 320 px, with and without 1.4.12's text spacing, in all three languages; light, dark and forced colours.
- The design walk gains the long-name and long-ID fixtures, keeps its document-width check, and adds a text-range check for spill that does not widen the page; the before is the two `v34-` captures in the 22 October bundle, the after taken beside it.
- `test/stylesheet.test.ts` pins the wrap on the rules that carry it; `npm run check` green with no test deleted or skipped; no control or element added; the progress bar kept.
