# VH-193 — A note before Create when levelling will need heavy limiting

## Intent

Landing a quiet recording with loud peaks on −16 LUFS can need the limiter to take off a great deal: about 8 LU on the 29-minute Teams recording (VH-106). That can make a voice sound flat, and today the user finds out only by listening to the result. This item adds an advisory pre-flight warning, beside the other audio-quality warnings, when the analysis pass predicts more limiting than a threshold the owner sets (question Q6, recommended 6 LU), so heavy processing is disclosed before Create (INTAKE.3). The words are row B11 of the wording sheet; spec §5.4 gains a row by correction S25.
