# VH-127 — The title card: General

## Intent

The owner asked on 2026-10-14 for an optional card before the video, with a toggle between General and Submission. General carries a heading and a subhead, so a video can say what it is before it starts. It opens the timeline's opening slot, dormant since VH-23, using the renderer VH-126 builds; Submission follows in VH-128.

## Acceptance criteria

- A title card control, off by default, with the choice of General or Submission (Submission is VH-128's); General takes a heading, required, and a subhead, optional, each with a length limit set in `src/config/`.
- With the card on, it joins before the trimmed source by a hard cut, silent, held for a duration set in `src/config/`; the source's timing, the trim and the closing are otherwise unchanged.
- Text wraps, and shrinks within a floor, to fit; long words and non-Latin scripts draw; text that will not fit is refused at the field, saying what to do, never clipped.
- The card's text never reaches the logger, the diagnostics bundle, the suggested file name or the file's metadata.
- The size and time estimates count the card; loudness is still measured on the source only; the boundary fade (D3) applies at the join.
- The page's new words are in all three language tables, by VH-105's sheet route.
- Spec §4 and §9.1 say so, in text the owner approves (docs/ is protected).
- `npm run check` green; checked in Chrome on a sample, with the card on and off, trimmed and not.
