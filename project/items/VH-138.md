# VH-138 — The page audited again, to the 2026-10-01 standard

## Intent

The owner asked on 2026-10-20 for the three audits of 1 October 2026 to be run again on the live page: VH-104's walk as a first-time member of staff, the WCAG 2.2 gap review and VH-124's page audit. Since then the page has gained translations, the Staff video / Student submission switch, Video language, the title cards, the Internal use only closing, the decode-damage warning, the accessibility statement, a save line of its own and a time left. The aim is to find every place where the live app falls short of the standard those audits set, then plan one phase that brings it back up. This item audits and plans; it changes no product code.

## Acceptance criteria

- A bundle under `reviews/2026-10-20/`, self-contained like the 1 October one, with a README naming its files, the baseline SHA and how the work was done.
- The audit: a verdict; findings V-01 onward, each with what was seen, the standard it breaks, a direction and its evidence; ranks 1 to 3 as defined on 1 October; What held up; Set aside, with reasons.
- A regression table marking every U- and A- finding and every VH-124 state as holds, regressed, partly or superseded, with the evidence.
- The state-by-state table with VH-124's five columns for every state, the new ones included.
- All 86 WCAG 2.2 criteria judged against the live app; the exceptions to record under spec §9.3; the accessibility statement's claims checked.
- What only a person can judge, carried forward, with what has been done since and wish lines cited rather than duplicated.
- `evidence/` holds the screenshots, each named by its finding, made from ffmpeg fixtures only.
- Codex astra's blind report and its adversarial critique of the merged draft are kept as written; each of its findings is verified live or in source.
- One phase proposed under `### Phase 3 — <name>` with items numbered from VH-139, each with a file whose criteria carry its findings' clauses; recorded as PLAN-3; every finding left out is a line; spec corrections are wish lines; nothing built.
- `node tools/check.mjs` and `npm run check` green; committed as `VH-138: …` with `Verify:` and `Checked:` lines.
