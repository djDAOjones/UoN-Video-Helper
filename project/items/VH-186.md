# VH-186 — Small words: shorter System check labels, capitals for values shown alone, the unscanned caption warning completed

## Intent

Three small wording defects, grouped because each is a few strings and none changes behaviour. The System check's row labels carry their explanation in brackets and wrap on a phone (INTAKE.5). A value shown alone in Video properties, such as "unknown" or "less than a second", starts lower-case where every other value starts with a capital (INTAKE.7). The warning for a file whose caption tracks could not be checked stops at "will not be carried over", where the warning for a checked file goes on to say where captions must come from (VH-138.5). The words are rows B1 to B3 of the wording sheet.

## Acceptance criteria

- The System check rows read as the sheet's B1 approves, with no bracketed explanation left but the format names.
- A value shown alone in Video properties or the System check starts with a capital in English (sheet B2); the same words inside a sentence stay lower-case. Every call site of `format.unknown`, `format.lessThanASecond` and `format.fewSeconds` is read and listed in the close as alone or in a sentence.
- The unscanned warning goes on with the scanned one's caption passage (sheet B3); no new sentence is written for it.
- The English is the sheet's, as the owner approved it; the Chinese and Malay rows are the agent's machine drafts, through the filled sheet and `scripts/strings-table.mjs`, marked so for a native reader; `src/i18n/tables.test.ts` is green, and any key removed goes from all three tables and `src/i18n/sheet.ts` in the same commit.
