# VH-202 — The third pass's fix plan, put to the owner in one ask

## Intent

The third pass's fix-plan stage, as VH-175 was the second's. The report's rank 1 and rank 2 findings become fix items, Codex astra critiques the plan, and the owner approves it in one ask, with the open disagreements and the rank 3 proposals beside it. Nothing contested is built before the owner answers. It changes no product code.

## Acceptance criteria

- **Planned with `verbs/plan.md`.** Every rank 1 and rank 2 finding sits in a fix item in Phase 8, between VH-202 and VH-203, each with a file to the schema whose criteria carry VH-203's stage rule; each item one session's work; an order with its reason; short backlog lines within the 1,000-word budget.
- **Rank 3** findings go to the owner as proposals; any not taken become wish lines.
- **Codex astra's critique of the fix plan**, from a brief, saved verbatim in the bundle; each point applied, refused with a reason, or for the owner.
- **One ask to the owner:** the fix plan; each open disagreement with both positions; the rank 3 proposals; any remedy that would add a control, checkbox or element, flagged and recommended against. The answer quoted in a decision. Only a contested remedy waits; approved items go ahead.
- A rank 1 finding may be fixed at once on the owner's word.
- A PLAN-8 entry whose Items line names the fix items; `node tools/view.mjs` run; the gate and the checker green; the commit carries `Checked: gpt-6-astra — <verdict> — the fix plan`.
