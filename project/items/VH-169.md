# VH-169 — A pressed state for each button kind, as Carbon's buttons have

## Intent

No rule styles `:active`: held down, Choose file and Create show their hover fill, and a secondary button the same (V-39). Carbon's button specification gives every variant an active state, and VH-163 walks active among the states. This item gives each existing button kind a pressed look, with no control or element added, from an existing colour role if one gives a distinct fill at 7:1 with its text, or else from an active role measured in every context.

## Acceptance criteria

- V-39: primary, secondary and danger buttons, and the file chooser's button, each look different pressed than hovered; disabled still wins; the segments judged and either given a pressed look or recorded as needing none.
- An existing role used first; any new active role defined in light, dark and the blue band, its text pair measured at 7:1 in `test/contrast.test.ts`, and forced colours left to the system.
- The mouse-down measurements taken before and after, kept beside the item's evidence; three languages, light, dark and forced colours.
- `test/stylesheet.test.ts` pins the pressed rules; `npm run check` green with no test deleted or skipped; no control or element added.
