# VH-145 — The page's shape from the tokens: the browser's defaults set, the weights named, the twin rules folded

## Intent

VH-124 put every length, colour and line height in `app.css` on a token, and a stylesheet test holds that. The design pass of 21 October found where the system still stops: wherever `app.css` is silent the browser decides — a 14 px gap under every status line, a 2 px inset on the switchers' legends, the radios' margins, a phone dialog's gutter, the monospace face — and the weights are literals no token names (V-19). The stylesheet has also grown an unused rule and two pairs of identical ones (V-25). This item closes the boundary with the tokens that exist, names the weights, and folds the identical rules, so the page is drawn from one system and the test can see it.

## Acceptance criteria

- V-19: `.status` sets its whole margin from the spacing scale and reserves a compact line, the empty save line's reset kept; the segmented legends take `padding: 0`; `.radio input` takes `margin: 0`, the described radio's alignment kept; `.select` takes a line height from the tokens or the native one is recorded; `.choice` takes `min-width: 0`; the dialog's phone gutter is the intended 16 px; the errors panel's intro has a class; no computed margin, padding or gap in the walker's token sweep falls off the scale except the structural exemptions and forced colours.
- V-19: the weights are type roles in `tokens.carbon.css` — regular 400, semibold 600, bold 700 — used in place of every literal weight in `app.css`; `test/stylesheet.test.ts` fails on a literal `font-weight` and on the defaults this item sets going missing; a monospace stack is named beside the brand's faces in `tokens.brand.css`, or the diagnostics' face is recorded as an exception in a decision.
- V-25: the unused `.result-link` deleted; the two identical link rules (`.footer-contact-link`, `.notification-link`) and the two identical result-line rules (`.closing-result`, `.trim-result`) each grouped under one selector; no class renamed in the markup.
- Nothing moves that the 20 October and 21 October walks did not ask to move: the walker's captures at 1280, 390 and 320 px, light, dark and forced, compared with the design pass's; tests by category; `npm run check` green with no pin loosened; checked in Chrome.
