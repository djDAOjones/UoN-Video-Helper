# VH-160 — A link to the feedback form on its own line under Send feedback

## Intent

For the public release the owner wants a link to the feedback form at <https://forms.cloud.microsoft/e/Meg347QQvs>, near the bottom of the page. With many more users, a form is easier to gather opinions through than email. The owner wants the page simple, so this is one footer link and not a new control. It replaces nothing (PLAN-6):

- **Send feedback** stays as the route for reporting a problem. It prepares an email with the build and the recent log lines, and the form cannot carry those (VH-93).
- **The two help links** stay as the route for help with using the tool: Creators team on Teams, and the learning content team's email (VH-130, VH-148).
- **The form** is the route for what people think of the tool.

## Acceptance criteria

- One link on its own line directly under the Send feedback button, inside the footer band and above the version line. It is not a button and not a second control beside Send feedback. It is a 44 px target like `.footer-contact-link` (WCAG 2.5.5), styled from existing tokens, with no new literal.
- The address lives in `src/config/feedback.ts`, beside `CREATORS_TEAM_URL`, as `FEEDBACK_FORM_URL`. The link opens in a new tab with `rel="noopener noreferrer"`.
- The link carries nothing from the page: no query string, no filename, no media characteristic, no build ID (rules, no media egress). A test pins the exact address.
- Its words say alone where it goes and end with the page's own "(new tab)" phrase, as VH-153 leaves it. The English is the agent's draft, for example "Fill in the feedback form (new tab)".
- The words are in all three language tables and `index.html`'s static English, with a sheet note in `src/i18n/sheet.ts` saying what the link is and that "(new tab)" stays. The Chinese and Malay are the agent's drafts, matching each table's existing "(new tab)" form, for the campus colleagues to check (VH-105.2).
- A following of the link raises no "Leave site?" during a running job, because it opens a new tab. This is checked in Chrome.
- Spec §9.2 and §11 name the feedback email as the one feedback and outbound route. The correction is drafted as a wish line for the owner, because `docs/` is protected and VH-159 has applied Phase 5's rows.
- Checked in Chrome in all three languages, at 1280 and 320 px, in light, dark and forced colours. `npm run check` green with no new skip.
