# VH-162 — The release cut: product version 0.2.0 and the Xerte package

## Intent

The public release is 0.2.0. It is a release before v1: spec §13 is not yet complete, because criterion 10's walk is done by a person and criterion 1's EchoVideo upload is not yet confirmed (PLAN-6). This item sets the version and builds the package the owner uploads to Xerte under VH-14. It also proposes to the owner the hosting wording in the documents the owner signs.

## Acceptance criteria

- `package.json`'s `version` is `0.2.0`, and the version line reads `v0.2.0+YYYYMMDD.<sha>` from the release commit (DEV-INFRASTRUCTURE.md → "Version management").
- The release commit is tagged `v0.2.0` and the tag is pushed to `origin`.
- `npm run package:xerte` builds the zip from that commit on a clean tree, and the zip in `release/` is named for its build ID.
- Nothing on the page or in the statement claims v1 or full conformance. The machine-translation note and "partially compliant" stand.
- The brief's Direction and Platform sections and the profile's Hosting and deploy line describe GitHub Pages as the pilot and Xerte as the intended home. Replacement words are proposed to the owner, because both documents are owner-signed: Xerte is the public home and GitHub Pages is the unadvertised preview from `main`.
- `npm run check` green with no new skip.
