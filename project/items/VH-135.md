# VH-135 — Three page defects and the Xerte link

## Intent

Three small defects, each seen in a Chrome check, cost someone something today. A screen-reader user browsing the page can still find a discard question that has gone. A previous video's save and the next file's check share one status line, so one can overwrite the other's message. A switcher's chosen segment widens as its face turns bold and nudges its neighbour on every choice. With them goes the owner's answer on the accessibility statement's Equality Advisory and Support Service link: inside a Xerte frame that site may refuse to load, so the link opens in a new tab and says so.

## Acceptance criteria

- Once `withdrawDiscardQuestion` in `src/main.ts` runs (the switch, the trim, the file size, the closing), `#status` no longer holds the question's text.
- A save's message and the next file's check never overwrite each other: each is shown and said in full.
- Choosing a segment in the language switcher or the video-type switch moves no neighbour, in all three languages: each segment reserves its bold width.
- The statement's Equality Advisory and Support Service link opens in a new tab and says so in its words in all three languages (WCAG technique G201); no other link changes.
- Tests for each by category; `npm run check` green with no new skip; checked in Chrome at 1280 px and 375 px.
