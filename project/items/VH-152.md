# VH-152 — Tests that guard what the page draws: the Chinese date, the read line, None's reason

## Intent

Three of the run's tests guard less than they claim:

- VH-146's unbreakable-date test still passed for Chinese with the date made breakable again, because its fake measure makes the note the wider piece.
- VH-148's read-line test pins `summarise()`, which the page no longer calls. `closingResultText()` and `studentIdsHelperText()` are now called only by tests too.
- VH-144's shared None reason has no markup pin, and it is keyed to the colour rule rather than to None.

VH-146 also finds the card's date and caveat by matching the finished sentence. A template it cannot match becomes one unbreakable piece, refused with an error that no edit clears. No user sees any of this today, but it decides whether the next change is caught, so the item comes third.

## Acceptance criteria

R2-n is finding n under Rank 2 in the review. Rank-3 findings are named by their words there.

- **R2-12.** The card test also asserts that the date alone, one pixel short of its line, is refused, in all three languages. The review's mutation, which makes the date breakable again, now fails the test for `zh-Hans` too.
- **Rank 3, "VH-146 finds the date and caveat by matching the finished sentence".** If the renderer cannot find a template's date or caveat, the card wraps as ordinary text, never as one unbreakable piece. A test covers the case where they are not found.
- **R2-13.** Every function these tests pin has a caller on the page.
  - The read line's test pins the words `setSourceReadStatus` draws.
  - `summarise()`, `closingResultText()` and `studentIdsHelperText()` are either what the page calls, or are retired with their tests' assertions moved to what it calls, so no assertion is lost.
- **Rank 3, VH-144.**
  - A markup pin checks that each of the three locked controls' `aria-describedby` includes `closing-none-reason`.
  - None's shared reason shows when `type === 'none'`, not by the colour rule, and a test says so.
- **The gate.**
  - No change a user can see.
  - Tests by category.
  - No test loosened, deleted or skipped.
  - `npm run check` green.
  - `spike-cards.html` re-run if the renderer changes.
